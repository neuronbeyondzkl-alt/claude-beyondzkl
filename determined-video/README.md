# DETERMINED · 两分钟浓缩版

把罗伯特·萨波尔斯基（Robert Sapolsky）的《Determined: The Science of Life Without Free Will》（2023）浓缩成一支 2 分 08 秒的“热血 / 燃”风格视频：光、影、荧光粒子，配乐与音效全部按同一条节拍网格卡点。

画面、配乐、音效全部由代码生成：没有素材库，没有外部音频，没有 AI 生成的图片。

成片：`output/Determined_720p.mp4`（45 MB，放在仓库里便于下载）。1080p 版本体积约 180 MB，超过 GitHub 单文件建议上限，按下文“构建”一节在本地生成。

| 规格 | 数值 |
|---|---|
| 时长 | 128 秒（64 小节 × 2 秒） |
| 画面 | 1920×1080，30 fps，H.264 |
| 声音 | 48 kHz 立体声，AAC 256 kbps |
| 节拍 | 120 BPM，D 小调；每拍正好 15 帧 |

## 配色：封面双色 · 冷光与余烬

配色取自书封：封面上的头像由藏青色和橙色两种圆点组成。

| 角色 | 颜色 | 用在哪里 |
|---|---|---|
| 深渊底色 | `#03060C` → `#0B1A2E`（封面藏青 `#1A365D` 压暗） | 背景、阴影 |

| 高光核 | Loyel `#F4F7FB` | 粒子核心、正文 |
| 余烬（人、情绪、温度） | 封面橙 `#D3643E`、`#F0915E`、金 `#F6C08A` | 重点词、火焰、动作电位、前额叶 |

蓝色只用 Loyel 色板；橙色是从封面图上取样得到的，承担语义：凡是“人以为自己在做主”的地方都是橙色，凡是“因果链”都是蓝色。

## 光与影是怎么做的

- **背光剪影**：凡是头像出现，背后都放一盏光源，头像轮廓作为遮挡体，径向模糊出体积光，头像本身变成暗剪影，边缘透出光芒。剪影跟着粒子变形淡入淡出。
- **光柱 + 雾**：7 道斜射光柱穿过缓慢漂移的三层噪声雾，随底鼓和太鼓脉动。
- **景深**：按 1/深度 计算弥散圆，近处粒子变成大光斑，远处变柔，焦平面上的粒子保持锐利。
- **辉光**：6 级金字塔 Bloom，ACES 胶片色调映射，暗角，轻微颗粒。
- **文字**：每行字下方先压一层柔和暗影再加辉光，保证在粒子上也读得清；退场时从左到右烧成粒子飘散。

## 卡点是怎么保证的

`timeline.py` 是唯一的时间来源：鼓点、冲击、上升音、静默、故障、每一句文字的入场时间都写在这里。`audio.py` 按它合成声音，`render.py` 按它生成画面，所以两边不会漂移。另外 `audio.py` 会输出每帧的低频能量，画面整体亮度随之轻微起伏。

`check_sync.py` 会在成片上实测：对每个冲击点，找出画面亮度跳变最大的帧和声音起音最强的帧，报告两者的毫秒差。

## 构建

```bash
pip install numpy scipy opencv-python-headless numexpr pillow
./fetch_fonts.sh                 # 思源宋体 / 黑体、Oswald、Montserrat（SIL OFL）
python3 audio.py                 # → build/score.wav, build/envelope.npz（约 40 秒）
python3 render.py --stills 25,49 # 预览单帧 → build/stills/
python3 render.py --workers 4    # 完整视频 → build/determined.mp4（4 核约 7 分钟）
python3 check_sync.py build/determined.mp4
```

| 文件 | 作用 |
|---|---|
| `timeline.py` | 节拍网格、和声、鼓谱、冲击点、文案、粒子形体时间表、配色 |
| `audio.py` | 合成器：底鼓、军鼓、太鼓、Braam、弦乐固定音型、合唱、钢琴、主旋律、上升音、呼啸、故障音、混响、侧链、母带 |
| `formations.py` | 33 种粒子形体（每个 24,000 粒子），全部是时间的纯函数 |
| `render.py` | 投影、景深、体积光、Bloom、文字、火花、冲击波、调色、编码 |
| `check_sync.py` | 成片卡点实测 |

## 内容说明

- 视频里的句子是对书中论点的中文转述，不是原文引文。“人能做他想做的，却不能决定自己想要什么”出自叔本华（1839），与本书“意图从何而来”的论证相呼应。
- “一门没有自由意志的生命科学”是副标题的直译，不是中文版书名。
- “前额叶约 25 岁成熟”“《女巫之锤》把癫痫发作视为巫术迹象”“隔离模型（quarantine model）”对应书中的论证；“刹车失灵的车”是萨波尔斯基常用的比喻。表述都做了压缩。
