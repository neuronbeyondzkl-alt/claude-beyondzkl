# REWIRE · 重塑大脑（浓缩视频）

把 Nicole Vignola 的《Rewire: Break the Cycle, Alter Your Thoughts and Create Lasting Change》浓缩成一支 1 分 41 秒的燃向短片：光束、阴影、荧光粒子，配一首程序生成的 128 BPM “热血/燃”配乐，所有转场、文字出现与粒子爆发都卡在鼓点和音效上。

- 成片：`REWIRE.mp4`（1920×1080，30 fps，H.264 + AAC 256k）
- 配色：Loyel 渐变蓝（#F4F7FB → #263B54 十档）加中性白光，背景是低照度下的 #263B54 / #2E5076

## 内容依据

三阶段结构（Ditch the Negative / Shift Your Narrative / Boost the Positive）、“大脑是硬件，心理健康是软件”、“小径变公路”、注意力驱动可塑性、“大脑依靠一致性重塑自己”、手机/日记/视觉化/捷思、睡眠/运动/冥想/呼吸、生理叹息，来自书籍书评、Blinkist 摘要与作者在 Good Life Project 播客中的访谈。Hebb（1949）“一起放电的神经元会连在一起”是神经科学通用原理，用来解释“小径变公路”。

## 重新生成

```bash
./build.sh      # 安装依赖、下载 Noto Sans SC 字体、合成配乐、渲染并混流
```

分步运行：

```bash
python3 music.py                       # -> out/music.wav
python3 render.py --times 15.2 49.0    # 指定秒数渲染静帧到 out/frames/
python3 render.py --out out/rewire.mp4 # 完整渲染（4 核约 15 分钟）
```

| 文件 | 作用 |
|---|---|
| `timeline.py` | 唯一的时间来源：BPM、小节、事件表（鼓、音效、冲击）与字幕脚本。音频和画面都读它，所以永远同步 |
| `music.py` | numpy/scipy 合成全部声音：鼓组、贝斯、Supersaw 和弦、琶音、主旋律、Impact、Braam、上升音、反向镲、呼吸声，含侧链、混响与延迟 |
| `render.py` | 逐帧渲染：粒子双线性泼溅、多级 Bloom、体积光、阴影遮罩、冲击时的闪白/震屏/色散；每帧只依赖时间 t，可多进程并行 |
| `contact.py` | 把若干静帧拼成预览图，方便检查 |
