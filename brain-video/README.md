# 重塑大脑 · The Brain That Changes Itself（读书浓缩视频）

把诺曼·多伊奇（Norman Doidge）的《The Brain That Changes Itself》浓缩成一支约 2 分钟的"热血、燃"风格视频。画面由光、影和荧光粒子构成，配乐为程序生成的史诗预告片风格（120 BPM，D 小调）。音乐和画面共用同一份时间轴，所以每一次鼓点、撞击、上升音效都和画面上的闪光、粒子爆发、文字出现落在同一帧上。

成片：[`the-brain-that-changes-itself.mp4`](the-brain-that-changes-itself.mp4)（1920×1080，30 fps，H.264 + AAC，约 124 秒）

配色只用 Loyel 渐变蓝十档色值，加上作为阴影的黑色和作为文字高光的白色。

## 结构与卡点

每小节 2 秒（120 BPM），所有段落切换都落在小节强拍上。

| 时间 | 段落 | 画面 | 音乐与音效 |
|---|---|---|---|
| 0–8 s | 序章：机器大脑 | 顶光下一台"格子化"的机械大脑，功能模块随时钟逐拍点亮 | 低频持续音、时钟滴答、心跳；第 3 小节末反向扫音 |
| 8 s | **"错了。"** | 格子大脑炸成粒子，宽银幕黑边瞬间打开 | 冲击 + 铜管 BRAAM + 镲片 |
| 10–16 s | 片名 | 粒子聚合成"重塑大脑"，体积光放射 | 太鼓、弦乐固定音型渐入、上升音效 |
| 16–24 s | 神经可塑性 | 脑回由光线逐条点亮；军鼓处随机脑回闪亮 | 完整律动进入 |
| 24–32 s | 赫布定律 | 两个神经元在每一记军鼓上同时放电，连接逐次变粗 | 军鼓 = 放电 |
| 32–40 s | Case 01 感觉替代 | 倾斜摇晃的地平线（坠落感）→ 舌头传感信号上行，地平线归正 | |
| 40–48 s | Case 02 大脑地图 | 皮层"版图"随每一记底鼓扩张 | 底鼓 = 版图扩张 |
| 48–56 s | Case 03 中风之后 | 皮层—脊髓纤维断裂；新生侧支在电流音上逐条接通；**97%** 由粒子拼出 | 电流 zap 音 = 侧支生长；54 s 冲击 + 下潜低音 |
| 56–64 s | Case 04 想象的力量 | "真实弹奏"与"仅凭想象"两组琴键随十六分音符点亮，运动皮层同步扩大 | 固定音型每个音 = 一个琴键 |

| 92–100 s | 可塑性悖论 | 月光下的雪坡，一条雪橇轨迹越压越深 | 鼓组撤出，钢片琴琶音 + 心跳 |
| 100–116 s | 终章 | 三维神经网络旋转放电 → 脑回由中心向外逐拍扩散光波 | 全编制 + 主旋律高八度；115.5 s 全黑静默 |
| 116–124 s | 片尾 | 粒子重组为片名，黑边合拢，淡出 | 终极冲击 + 长混响尾音 |

## 内容依据

所有案例均来自原书章节：Cheryl Schiltz、Paul Bach-y-Rita 以及他父亲 Pedro 的中风康复（第 1 章）、Barbara Arrowsmith-Young（第 2 章）、Michael Merzenich（第 3 章）、Jeffrey Schwartz（第 6 章）、V.S. Ramachandran（第 7 章）、Alvaro Pascual-Leone（第 8 章）、"把幽灵变成祖先"（第 9 章）、Fred Gage 与成年神经新生（第 10 章）、Michelle Mack（第 11 章）。雪坡雪橇的比喻和"可塑性悖论"出自第 8 章。

> 【争议】成年人类海马体能否持续产生新神经元，在原书出版（2007）之后仍有争论：Sorrells 等（2018，*Nature*）报告成年后几乎检测不到，Boldrini 等（2018，*Cell Stem Cell*）则报告终生持续。视频沿用原书的表述。

## 重新生成

需要 Python 3（numpy、scipy）、Node 22、Playwright 自带的 Chromium 和 ffmpeg。

```bash
./build.sh                       # 配乐 → 逐帧渲染 → 合成成片
python3 music.py                 # 只重做配乐：build/score.wav + build/events.json
node render.mjs stills 8.1 54.4  # 抽查某几个时间点的画面：build/stills/*.png
```

| 文件 | 作用 |
|---|---|
| `timeline.json` | 全部字幕文案和出现时间（配乐也读它，为文字出现配"叮"声） |
| `music.py` | 合成配乐，同时导出每一个鼓点、冲击、音符的时间和逐帧响度包络 |
| `render/core.js` | 噪声、事件查询、发光贴图、文字缓存、泛光与暗角等后期 |
| `render/geometry.js` | 大脑轮廓与脑回、神经元、纤维束、雪坡、三维网络等几何 |
| `render/scenes.js` | 各场景、粒子编排、字幕动画和逐帧合成 |
| `render.mjs` | 启动本地服务，用无界面 Chromium 并行逐帧渲染并交给 ffmpeg |
