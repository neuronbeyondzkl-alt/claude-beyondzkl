# NEUROPLASTICITY · 神经可塑性粒子叙事网页

参考 [usta.agency](https://usta.agency/) 的「滚动驱动粒子形变」叙事形式，把主题换成神经科学中的**神经可塑性**。
随着页面向下滚动，32,768 个低饱和蓝荧光粒子依次重组为 7 个层级的结构，配乐的配器也逐层加厚。

## 运行

- **直接打开**：双击 `index.html` 即可（脚本已打包为普通 `<script>`，不依赖本地服务器）。
- **本地服务器**：`npm run serve`，然后访问 `http://localhost:8080`。
- **单文件版**：`npm run build:single` 生成 `dist/neuroplasticity.html`，CSS/JS 全部内联，便于发布到只接受单个 HTML 的环境。

浏览器需支持 WebGL2（Chrome / Edge / Firefox / Safari 15+）。配乐需点击「点燃配乐」或右上角「开启配乐」后才会播放（浏览器自动播放策略）。

## 九个画面与对应形态

| 序号 | 英文标题 | 层级 | 粒子形态 | 尺度 |
|---|---|---|---|---|
| 首页 | NEUROPLASTICITY | — | 皮层柱：彼此连接的锥体神经元网络。中央一个巨型锥体神经元（顶树突穿过标题），左右两个侧翼巨型神经元、中景与背景锥体神经元“森林”、两个包绕胞体的篮状细胞；轴突侧支以突触小体落在邻近神经元的树突上，右侧的回返侧支从标题上方横越，形成闭合的“回响环路” | — |
| 01 | BRAIN | 大脑 | 两半球（回/沟纹理、中央沟）、颞叶、小脑叶片、脑干、内部白质纤维 | ≈ 15 cm |
| 02 | NEURON & GLIA | 神经元与胶质细胞 | 锥体神经元（顶树突、基底树突、树突棘、有髓轴突与郎飞结、终末）、星形胶质细胞与毛细血管终足、少突胶质细胞 | 4–100 μm |
| 03 | SYNAPSE | 突触 | 突触前终扣（囊泡、Ω 形胞吐、线粒体）、突触间隙递质、蘑菇形树突棘与 PSD 受体、星形胶质包绕、新生树突棘 | ≈ 20 nm |

| 05 | CIRCUIT | 神经环路 | 海马三突触环路：EC → DG → CA3 → CA1 → 下托 → EC，含抑制性中间神经元与神经调质输入 | mm |

| 07 | COGNITION & BEHAVIOR | 认知与行为 | 冲刺的人形：头部大脑、脑 → 脊髓 → 四肢的运动指令脉冲、思维波环、速度线、地面冲击波 | ms – 一生 |

## 配色

- **主体（每个形态占 76%–87%）**：Loyel 渐变蓝 `#CCDBEB` `#9FBDDA` `#6C9AC4` `#497DAE` `#376392`，以及少量 `#E8EEF6` 高光。Bloom 辉光也染成同色系的蓝。
- **语义点缀（每个形态占 13%–24%）**：琥珀 = 动作电位 / 能量，薰衣草 = 神经递质 / 少突胶质，薄荷 = 星形胶质，珊瑚 = 受体 / 血管，水青 = 髓鞘纤维，兰紫 = 抑制性中间神经元 / 调制。
- 后处理采用**保色相的高光压缩**，粒子密集处保持低饱和蓝，不会叠加成白色。

## 页面内可调（右上角「荧光调节」）

| 控件 | 作用 |
|---|---|

| 标题荧光 0–200%（预设：柔光 / 标准 / 霓虹） | 只调节英文中空标题的蓝色描边与外发光，与粒子荧光分开 |
| 色彩丰富度 0–100% | 0% 时所有点缀色收回为低饱和蓝 |
| 粒子尺寸 50–160% | — |
| 配乐音量 0–100% | — |
| 英文标题字体 | 默认 Oswald（原站字体），可切换其他静态展示字体比对 |

设置会记在浏览器本地；右侧菱形导航可跳转层级，`Esc` 关闭控制台。

## 神经交互

| 操作 | 效果 | 对应的神经机制 |
|---|---|---|
| **点击**（触屏为轻点） | 在点中的神经突上诱发一次全或无的动作电位，沿树突 → 胞体 → 轴突 → 下一个神经元顺向传播；波前之后短暂变暗（不应期）。35 ms 内重复点击无效（绝对不应期） | 超阈值电流注入、动作电位、不应期 |
| **点得越快** | 放电频率用指数核估计（与电生理中估计瞬时放电率的方法相同）；频率越高，在途动作电位与全局电流的流速越快、脉冲越密、拖尾越长。左下角示波器实时显示膜电位与放电频率 | 频率编码（流速加快为示意，真实传导速度主要取决于轴突直径与髓鞘） |
| **持续快速点击** | 提示“高频刺激 → 诱导 LTP”，全网络沿生理方向放电一次 | 高频强直刺激诱导 LTP（示意） |
| **悬停** | 粒子不移动，只按距离衰减地变亮，并有向外扩散的 EPSP 涟漪与离子通道闪烁；停留越久膜电位越高，但始终低于阈值 | 阈下分级电位、时间总和、电紧张性衰减 |
| **光标扫过** | 扫过的路径短暂增强（变亮并传递更强的电流），约 2.5 秒后衰减 | 赫布式增强 / 早期 LTP |

其他动效：每个形态稳定下来后按自己的生理方向“首次放电”（树突→胞体→轴突、EC→DG→CA3→CA1、脑→脊髓→四肢）；层级切换时镜头推入粒子云并拖出光迹；导航菱形 = 郎飞结，切换层级时动作电位在结之间跳跃；标题在进入层级时像动作电位一样从左到右亮起；约 6% 的粒子有钙成像式的缓慢闪烁，以及偶发的自发去极化。所有动效在 `prefers-reduced-motion` 下减弱或关闭。

## 字体

- **英文标题：Oswald SemiBold（600）**，与原站 usta.agency 的标题字体一致（原站以 Fontsource 自托管 “Oswald Variable”，标题类 `.title` 为 Oswald 600，中空字使用 `-webkit-text-stroke`）。本项目从 Google Fonts 只请求单一字重 `Oswald:wght@600`，得到的是静态字体，大写字母没有重叠轮廓，描边时不会露出交叉线。
- **拉丁小字：Montserrat**（原站正文字体），用于引用文献、序号与 HUD 读数；中文正文仍为 Noto Sans SC。
- 标题为**中空描边 + 外层蓝色荧光**：描边默认 Loyel `#9FBDDA`，外发光三层依次为 `#9FBDDA` / `#6C9AC4` / `#497DAE`，强度由“标题荧光”单独控制。
- 控制台仍可切换 Anton、Bebas Neue 等静态字体比对。

## 配乐《REWIRE》

`src/audio.js` 用 Web Audio API 合成，没有音频文件，也不涉及版权。

- D 小调，136 BPM，16 小节循环：Dm–B♭–F–C | Dm–B♭–C–A | B♭–C–Dm–Dm | B♭–C–A–A
- 乐器：太鼓、底鼓、军鼓与滚奏、镲、失真贝斯、弦乐顿弓（16 分音符）、超锯齿和弦垫、英雄主旋律、铜管齐奏，另有卷积混响和延迟
- 配器强度随层级递进（1 → 5）：首页只有和弦垫、顿弓和太鼓，到「认知与行为」时全编制齐奏
- 每次切换层级触发一次冲击音效；点击时播放一声电生理监听器式的“哒”声，点得越快音调越高

### v2：修复“卡顿、杂音、消失”

v1 在主线程上实时排程每个音符。逐项排查后的原因与修复：

| 症状 | 原因 | 修复 |
|---|---|---|
| 卡顿 | 音符由主线程 `setInterval` 排程，只提前 0.14 s；粒子生成、整张纹理重传、Bloom 渲染或 GC 一阻塞，音符就迟到或挤在一起 | 用 `OfflineAudioContext` 把整段编曲按配器层级**预渲染成 6 条无缝循环分轨**，播放时只剩循环的 `AudioBufferSourceNode`，完全不依赖主线程计时；粒子纹理改为只上传变化的行 |
| 杂音 | 侧链压缩每拍把增益**瞬间**从 1 跳到 0.42；主旋律包络中段也有一次阶跃；贝斯失真无过采样产生混叠；各层叠加峰值达 3.2，压缩器与 1 ms 限幅器持续工作，使低频失真 | 侧链改为一拍长的平滑包络缓冲，以音频速率调制；包络全部改为斜坡；失真 4 倍过采样；各分轨按实测电平配平（峰值约 1.47），只保留一个很少介入的安全限幅器；混响发送高通 250 Hz |
| 消失 | 每次切换层级的 27 Hz 次低频冲击把整段混音压没约 1.5 s；标签页切回、来电或 iOS “interrupted” 后上下文停在挂起状态而按钮仍显示“开”；快速关再开存在竞态；iPhone 静音拨片会静音网页声音 | 冲击音效改为 42–80 Hz、峰值 0.5 并高通 38 Hz；按“用户意图 / 实际状态”分开管理并串行执行生命周期操作，被打断时按钮显示“点击恢复配乐”，下一次点击即恢复；切后台先淡出再挂起；设置 `navigator.audioSession.type = 'playback'` |

渲染从页面空闲时开始（无需手势），和弦垫约 1 秒内就绪即可起播，其余分轨渲染完成后在下一拍对齐加入。内存约 43 MB（32 kHz 立体声）。

## 目录结构

```
index.html            页面结构与全部文字内容
assets/style.css      样式（Loyel 色板 token、中空霓虹字、响应式）
assets/app.js         打包产物（由 src/ 构建，已提交，可直接使用）
src/main.js           滚动、布局、控制台、主循环
src/interact.js       神经交互：点击动作电位、放电频率、悬停分级电位与赫布尾迹、示波器、跳跃式导航、LTP 提示
src/particles.js      Three.js 粒子场：形态纹理、形变着色器（动作电位波、悬停、钙闪烁）、Bloom、光迹、背景与色调映射
src/shapes.js         9 种形态的程序化生成
src/audio.js          配乐：离线预渲染分轨 + 循环播放 + 生命周期状态机
src/noise.js          种子随机数与 Simplex 噪声
scripts/build-artifact.mjs  单文件版构建脚本
```

## 开发

```bash
npm install
npm run build          # 打包 src/ → assets/app.js
npm run dev            # 监听模式
npm run build:single   # 额外生成 dist/neuroplasticity.html
```

## 性能与无障碍

- 小屏幕或 CPU 核数 ≤ 4 的设备自动减半粒子数（16,384），并限制像素比。
- `prefers-reduced-motion` 时减弱形变炸散、自转和脉冲。
- 标签页隐藏时淡出并暂停配乐，切回后自动恢复（被系统打断时提示点击恢复）。
- 不支持 WebGL2 时，文字内容与配乐仍可正常使用。
