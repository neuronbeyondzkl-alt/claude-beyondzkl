# 最会用脑 · 一支 2 分 12 秒的光影短片

成片：[`最会用脑.mp4`](最会用脑.mp4)（2 分 12 秒 · 1920×1080 · 30 fps · H.264 + AAC · 约 48 MB）

用光、影和荧光粒子回答一个问题：**什么样的人，才算“最会用脑”？**

> 最会用脑的人，不是用脑最多的人，而是把脑用得最「对」的人——
> 知道何时聚焦、何时放空；知道自己不知道；敢于被改变，也懂得停下来。
> 一句话：**做自己大脑的指挥家。**

全片只用 Loyel 渐变蓝十档色值，粒子以叠加混合发光，再经两级降采样模糊做辉光。配乐是程序化合成的史诗风格：120 BPM，D 小调，高潮时升到 E 小调，鼓点、冲击和静默都与画面逐拍对齐。

## 怎么重新生成

需要 Node 18+（带 Playwright 与 Chromium）、Python 3（numpy、scipy）和 ffmpeg。

```bash
cd brain-film
node fetch-fonts.mjs        # 改了片中文字后才需要：重新下载只含所用字符的 Noto 字体子集
python3 music.py            # 合成配乐 → music.wav（约 45 秒）
node capture.cjs            # 逐帧渲染并混入配乐 → 最会用脑.mp4（CRF 20，约 100 MB；仓库里放的是两遍编码 2.6 Mbps 的版本）
node capture.cjs --stills 50,76,106 /tmp/stills   # 只导出几张静帧做预览
```

| 文件 | 作用 |
|---|---|
| `timeline.json` | 画面与配乐共用的节拍、段落、冲击点 |
| `render.js` | 确定性的逐帧渲染器：大脑点云、粒子队形、弹簧物理、光柱、辉光、文字动画 |
| `scene.html` | 1920×1080 画布与字体 |
| `capture.cjs` | 无界面 Chromium 逐帧截取，经管道交给 ffmpeg 编码 |
| `music.py` | 配乐合成与母带处理 |
| `fonts/` | Noto Serif SC / Noto Sans SC 子集（SIL OFL 1.1）；英文字体复用 `../assets/fonts/` |
