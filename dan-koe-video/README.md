# DAN KOE · 燃 —— 光、影与荧光粒子的思想短片

一支 86 秒的 1080p 短片，用光束、剪影和荧光粒子，把 Dan Koe 的核心观点浓缩成三幕。配乐是程序合成的热血史诗风（D 小调，128.57 BPM），每一次鼓点、冲击、呼啸声都和画面逐帧对齐。

成片：`output/dan_koe_ignite.mp4`

## 卡点是怎么做到的

`timeline.py` 是唯一的时间来源：一拍正好等于 14 帧（30 fps）和 22,400 个采样点（48 kHz），所有底鼓、军鼓、冲击、呼啸、上升音效、静默和画面场景都按小节/拍写在这里。`music.py` 和 `render.py` 读的是同一张表，所以声音和画面之间不存在“手动对齐”的误差。

| 声音事件 | 画面反应 |
|---|---|
| 底鼓 / 太鼓 | 光核脉动、镜头微推、粒子“呼吸”、高潮段光束频闪 |
| 军鼓 | 光芒与横向光晕闪动 |
| 冲击 + 重低音 | 白闪、冲击波光环、粒子爆散、尘埃被气浪推开、镜头震动 |
| 呼啸声（峰值落在换卡的那一拍） | 一道斜向扫光划过画面，粒子从旧字飞向新字 |
| 上升音效 | 光核增亮、镜头缓推、轻微抖动 |
| 静默的一拍 | 全场熄灯，只剩粒子坍缩成一点 |
| 闪烁铃音 | 粒子成形瞬间的星点闪烁 |

`check_sync.py` 会从成片里重新测量：音频起音强度与画面亮度上升的互相关峰值在 0 帧。

## 配色

整片只渲染一个亮度通道，最后通过 Loyel 渐变蓝色板（#263B54 → #376392 → #9FBDDA → #F4F7FB）做渐变映射着色，暗部向近黑延伸、最高光到纯白，没有任何色板以外的色相。

## 重新生成

```bash
pip install numpy scipy opencv-python-headless pillow
bash build.sh        # 合成音乐 → 渲染 2600 帧 → 响度归一化到 -14 LUFS 并混流
```

字体为 Noto Sans CJK SC（SIL OFL），脚本会自动下载到 `fonts/`。

## 内容来源说明

画面文字是对 Dan Koe 公开内容的提炼与转述，不是逐字引用，主要来自：

- 2026 年 1 月在 X 上广泛传播的长文 *How to fix your entire life in 1 day*：身份先于行动、反愿景/愿景、目标是感知的透镜、把人生设计成游戏（胜利条件 / 赌注 / 规则）、一年·一月·每日的目标层级。
- 著作 *The Art of Focus*：专注、精神熵（以自我设定的目标创造心智秩序）、无常与自我实验。
- 他关于“一人企业”、自学、通才、写作与杠杆的长期观点，以及“在 AI 内容泛滥的时代，唯一独特的是你”这一表述（据二手摘要）。
